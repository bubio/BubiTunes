This directory vendors a subset of zlib, a general-purpose data
compression library, for use on Windows, where SwiftPM cannot resolve
the CZlib systemLibrary target against a system zlib. Only the inflate
(decompression) sources needed to decode gzip streams are included.
On macOS and Linux the package keeps using the system zlib instead
(the CZlib target stays a systemLibrary there; see Package.swift).

  Source:  https://zlib.net/zlib-1.4.tar.gz
           (also published at https://github.com/madler/zlib, tag "v1.4")
  Version: 1.4
  Files:   include/zlib.h, include/zconf.h (unmodified upstream headers)
           include/shim.h (same one-line shim as Sources/CZlib)
           adler32.c, crc32.c, crc32.h, gzguts.h, inflate.c, inflate.h,
           inffast.c, inffast.h, inffixed.h, inftrees.c, inftrees.h,
           zutil.c, zutil.h (unmodified upstream sources)

To update, replace the files above with those from a newer upstream
release tarball and adjust the version recorded above.
